# 📊 Customer Value & Marketing ROI Analysis

## Overview

This project demonstrates an end-to-end Business Analytics workflow using Python, SQL, MySQL, and Tableau.

The project covers:

- Data Generation
- Data Cleaning
- Database Design
- SQL Business Analysis
- KPI Analysis
- Interactive Tableau Dashboard
